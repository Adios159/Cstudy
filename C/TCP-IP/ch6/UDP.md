# UDP
## UDP의 특성
- UDP는 패킷 전송 중 상대방의 수신여부를 확인하지 않는 소켓이다
- 심지어 패킷 분실의 위험도 있다
- 그래서 TCP 보다 신뢰성이 떨어지기도 한다
- 그러나 생각보다 그런 데이터 손실이 자주 일어나지 않고 TCP 보다 전송 속도가 빠르며 구현 난이도가 낮다.
- 그래서 특정 상황에서는 TCP 보다 높은 성능을 발휘한다.
- UDP는 호스트에서 전송된 패킷을 어떤 UDP소켓에 넣을지 판단하여 전달하는 역할을 함
## 효율적인 UDP 사용
- UDP소켓의 손실이 그렇게 자주 일어나는것은 아님
- 그래서 손실이 일어나도 크게 상관없는 파일(멀티미디어 데이터 같은 것들)전송에 빠른 속도를 위해 사용된다
- 압축파일은 하나의 패킷이라도 손실되면 압축 해제가 어려우므로 반드시 TCP로 전송함
- TCP가 UDP보다 느린 2가지 이유
  1. 데이터의 송수신 이전, 이후에 거치는 연결 설정 및 해제 과정
  2. 데이터 송수신 과정에서 거치는 신뢰성 보장을 위한 흐름제어
## UDP서버의 구현
- UDP서버는 클라이언트외 연결되어 있는 상태로 클라이언트와 통신하지 않음
- 따라서 listen, accept함수의 호출이 불필요하다
- 그리고 통신을 위해 필요한 소켓이 서버, 클라이언트 모두 하나만 있으면 됨
