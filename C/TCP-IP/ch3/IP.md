# IP주소
## 인터넷 주소
IP주소: 인터넷에서 데이터를 송수신 할 목적으로 컴퓨터에게 부여하는 값
| 종류 | 설명 | 
| --- | --- |
| IPv4 | 4바이트 주소체계 |
| IPv6 | 16바이트 주소체계 |
---
## IPv4 주소체계
| 클래스 | 1바이트 | 1바이트 | 1바이트 | 1바이트 |
| --- | --- | --- | --- | --- |
| A | 네트워크 | 호스트 | 호스트 | 호스트 |
| B | 네트워크 | 네트워크 | 호스트 | 호스트 |
| C | 네트워크 | 네트워크 | 네트워크 | 호스트 |
| D | 멀티캐스트 | 멀티캐스트 | 멀티캐스트 | 멀티캐스트 |
## 데이터 수신
1. 전송할 컴퓨터의 IP주소를 알아낸다
2. 네트워크 주소만을 먼저 참조하여 해당 네트워크로 들어간다
3. 해당 네트워크의 라우터가 호스트 주소를 참조하여 데이터 전송
## 클래스 별 네트워크 주소/호스트 주소의 경계
클래스 별 첫번쨰 바이트 범위
| 클래스 | 범위 |
| --- | --- |
| A | 0 - 127 |
| B | 128 - 191 |
| C | 192 - 223 |
