# 기존 에코 클라이언트의 문제점과 해결방법
## 기존 에코 클라이언트
- 클라이언트와 서버 모두 모든 데이터를 한번에 주고 받는것을 기대하고 있음 
- 그러나 전송하는 데이터의 크기가 커지면 운영체제가 패킷 단위로 전송
- 이렇게 되면 클라이언트가 서버의 모든 데이터를 전송받지 못하는 사고 발생
## 해결방법
- 해결방법은 간단함
- read 함수를 반복 호출하여 모든 데이터를 수신받을 떄까지 반복하면 된다. 
---
### 코드해설
```C
while(recv_len < str_len)
{
    ...
}
```
- != 연산자로 반복문의 조건을 설정하게되면 recv_len이 초과될 경우 무한 루프에 빠지게 된다.
- < 연산자로 설정하여 무한루프에 빠지는 사태를 예방한다
## 어플리케이션 프로토콜의 정의
- 챕터4에 구현한 코드에서 Q를 누르면 종료 할 수 있는 기능이 있다. 
- 이와 마찬가지로 데이터의 끝을 파악할 수 있는 별도의 약속을 정의할 수 있다
- 이런것들이 여러가지 모여 이루는 것이 **어플리케이션 프로토콜** 이다
