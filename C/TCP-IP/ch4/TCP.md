# TCP (transmission Control Protocol)
## TCP/IP 프로토콜 스택
  1. 애플리케이션 계층
  2. TCP/UDP 계층
  3. IP 계층
  4. 링크 계층
## 탄생 배경
네트워크는 소프트웨어만의 문제가 아닌 하드웨어적인 시스템이 구축되어야 가능한 일. 
이를 위해선 많은 전문가들이 필요하고 이들간의 논의를 통해 만들어진 다양한 약속들도 필요하다. 
그렇기에 이를 작은 문제로 나누어 해결하는것이 효율적이고 이렇다보니 여러개의 프로토콜이 나오게 되었으며 이들간의 계층구조를 이루게 되었다.
## 각 계층에 대한 설명
### 링크 계층
- 네트워크 표준과 관련된 프로토콜을 정의하는 영역
- 두 호스트의 물리적인 연결에 대한 표준을 제공하는 역할도 한다
### IP 계층
- 데이터 전송을 위한 경로를 선택하는 문제를 해걀하는 계층
- 비 연결지향적이며 신뢰할 수 없는 프로토콜이다
- 데이터 전송 중 오류가 생기면 다른 경로를 선택해 주지만 데이터 손실과 같은 오류 발생 가능성 존재 
### TCP/UDP 계층
- IP계층에서 알려준 정보를 바탕으로 실제 송수신을 담당하는 계층
- UDP가 조금 더 간단함
- TCP는 신뢰성 있는 데이터 전송 담당
- 호스트 간의 패킷전송에 대한 실시간 상황을 주고 받음으로써 전송 상태를 실시간으로 확인함
