# half-close
## 일반적인 종료의 문제점
- 일반적으로 통신을 종료할 떄는 close함수를 이용한다
- 함수를 호출하면 데이터의 수신과 송신 둘 다 불가하게된다
- 이런 문제를 해결하기 위해 스트림의 일부만 종료하는 half-close방법을 사용한다
## 스트림과 소켓
- 데이터의 송수신이 가능한 상태를 보고 스트림이 형성되었다고 함
- 이런 스트림은 단방향으로만 형성되기 때문에 양방향 통신을 위해선 두 개의 스트림이 필요하다
- 두 호스트의 소켓이 연결되면 각 호스트별로 입력, 출력 스트림이 생성된다
- 한 호스트의 출력 스트림은 다른 호스트의 입력 스트림이고 반대도 성립함
- half-close는 이 두 스트림 모두 끊는 것이 아닌 한 쪽 스트림만 끊는것임
## shutdown 함수
- shutdown함수는 호출시 두 개의 인자를 받음
  1. 종료할 소켓의 파일 디스크립터
  2. 종료방법에 대한 정보
| 인자 | 설명 |
| --- | --- |
| SHUT_RD | 입력 스트림 종료 |
| SHUT WR | 출력 스트림 종료 |
| SHUT_RDWR | 입출력 스트림 모두 종료 |
## half-close 가 필요한 이유
- 서버가 데이터를 전송하고 클라이언트는 잘 수신했다는 의미로 임의의 데이터를 보낸다는 상황을 생각해보자
- 클라이언트는 서버가 데이터를 얼마나 보낼지 모른다
- 끝을 의미하는 문자를 보낼수도 있지만 그 문자가 서버가 보낼 데이터와 겹칠수도 있다.
- 이를 해결하기 위해 서버는 클라이언트에게 EOF를 보낸다
- close도 EOF를 보내지만 임의의데이터를 클라이언트가 보낼수는 없다
