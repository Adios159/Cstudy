# 소켓의 프로토콜과 그에 따른 데이터 특성

## 프로토콜 이란?
컴퓨터 상호간의 대화에 필요한 통신 규약. 즉 컴퓨터들의 소통 방식 

## 프로토콜 체계
| 이름 | 프로트콜 체계 |
| --- | --- |
| PF_INET | IPv4기반 인터넷 프로토콜 |
| PF_INET6 | IPv6기반 인터넷 프로토콜 |
| PF_LOCAL | 로컬 통신을 위한 unix 프로토콜 체계 |
| PF_PACKET | 저수준 소켓을 위한 프로토콜 체계 |
| PF_IPX | IPX 노벨 프로토콜 체계 |
---
## 소켓 함수의 구성
```C
#include <sys/socket.h>

int socket(int domain, int type, int protocol);
```
- domain: 소켓이 사용할 프로토콜 체계
- type: 소켓의 데이터 전송 방식
- protocol: 사용 할 프로토콜 정보 
---

## 소켓의 타입
데이터의 전송 방식, socket함수의 두 번째 인자로 전달. 
대표적인 두 가지 방식 소개

### 연결지향형 소켓(SOCK_STREAM)    
- 중간에 데이터가 소멸되지 않고 목적지로 전송
- 전송 순서대로 데이터가 수신
- 전송되는 데이터의 경계가 존재하지 않음

**경계가 존재하지 않는다 = 나뉘서 보내도 한번에 전부 수신이 가능하다.**
> Q. 소켓의 버퍼가 꽉 차면 어떻게 되나요?
>
> A. 버퍼가 차면 데이터 수신을 중단하게딤. 따라서 버퍼가 모두 차도 데이터 유실 위험 없음
---
### 연결지향형 소켓(SOCK_DGRAM)
- 전송된 순서에 상관없이 가장 빠른 전송 지향
- 데이터 손실의 우려가 있음
- 전송되는 데이터의 경계가 있음
- 한번에 전송 가능한 데이터의 크기가 있음
