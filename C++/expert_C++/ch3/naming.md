# 명명 규칙
- 변수, 함수의 이름을 지을 때 컴파일러의 규칙 이외에도 관례가 있다
- 이는 동료 프로그래머 들이 나의 코드를 볼 떄 도움이 된다
- 기본적인 것으로는 다음과 같다
  1. 두 객체를 명확히 구분할 수 있는 이름
  2. 변수의 위치(전역, 블록 내)를 구분할 수 있는 이름
  3. 간결하고 정확한 이름
  4. 용도가 명확히 드러난 이름
  5. 통상적으로 사용되는 용어들에 준말이 있다면 사용해도 좋다 
## 명명 규칙
### 카운터
- 반복문 내 카운터 변수를 쓸 떄 i로 쓰는 경우가 많다.
- 최상위 반복문은 i를 쓰고 이후 중첩 시 j, k, l...등 알파벳 순서대로 사용한다.
- inner_counter, outer_counter처럼 명시적으로 사용하기도 한다
### 접두사
- 변수의 성격 별로 접두사를 붙일 수 있다
- 통상정으로 사용되는 접두사는 다음과 같다
| 용도 | 접두사 | 
| --- | --- |
| 클래스 내 멤버 | m, m_ |
| 스태틱 변수 | s, ma, ms_ |
| 상수 | k, 전체 변수명을 대문자로 작성 | 
| 불리언 자료형 | b, is |
### 헝가리안 케이스
- 한글자 접두어 대신 접두어를 길게 쓰는 방법
- 변수명이 난해해져 싫어하는 사람도 많음
### 게터와 세터
- 스태틱 변수나 프라이빗 변수에 접근할 떄 getter, setter함수를 사용해 데이터를 조작한다
### 대소문자 활용
- 변수명에 대소문자를 섞어 쓸 수 있음
- 스네이크 케이스: 언더바를 사용해 띄어쓰기를 표햔하여 소문자 만으로 변수 이름 작성(is_full)
- 카멜 케이스: 띄어쓰기 부분은 대문자를 이용하여 변수이름 작성, (isFull)
### 네임스페이스
- GUI를 갖춘 프로그램을 작성하는 경우를 생각해보자
- help를 이름은 메인 메뉴에서도 쓸 수 있고, 메인 메뉴의 하위 메뉴에서도 쓸 수 있다
- 이를 네임스페이스를 통해 구분해놓으면 좋다
