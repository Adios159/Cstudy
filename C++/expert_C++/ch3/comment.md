# 주석
## 주석을 작성하는 이유
- 단순히 코드만 봐서는 이해가 안되는 것들이 있음
- 주석을 통해 코드를 쓸 당시의 나의 생각을 전달할 수 있음
## 주석의 종류
### 사용법을 알려주는 주석
- 클라이언트에게 코드의 사용법을 알려주기위해 작성
- 코드만으로 드러나지 않는 함수 호출 전후에 만족시켜야 하는 특징을 작성
- 함수가 던지는 예외도 작성함
- 또한 함수가 반환하는 값이 구체적으로 어떤 값인지
### 복잡한 코드를 설명하는 주석
- 실전에서는 프로그램에 들어가는 알고리즘이 복잡할 수도 있음
- 이런 경우에는 코드에 사용되는 알고리즘과 반복문, 조건문의 불변 속성을 주석으로 적어주면 좋다
- 먼저 코드에 적용된 알고리즘에 대략적인 설명을 적고 이해가 필요한 개별 라인에 인라인 주석을 넣는다
### 메타 정보 제공을 위한 주석
- 메타 정보란 코드의 구체적인 동작이 아닌 코드의 세부정보를 표현하는것을 말한다
- 예를 들어 코드 작성자, 작성 시각, 버전 정보, 다음에 할 일등을 적어놓는다
## 주석 스타일
### 문장 단위 주석
- 문서화에 소홀해지지 않는 방법은 매 문장 마다 주석을 추가하는 것이다
- 하지만 매 문장마다 달게되면 코드가 더러워질 수 있다.
### 머릿말 주석
- 소스 파일의 첫 머리를 항상 표준 주석으로 시작하는 방법도 있다
- 주로 메타정보를 작성한다
### 임의 주석
- 정해진 형식에 관계없이 필요한 경우 주석을 넣는다
