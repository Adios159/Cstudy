# 코드 분해
- 소스 코드를 열어보았을 때 수백줄에 달하는 함수와 여러 중첩이 있다면 보기가 어려울 것이다.
- 이를 해소하기 위ㅏ해 코드 분해를 한다
- 한 함수가 여러가지 일을 한다면 그 안의 작업을 꺼내 헬퍼 함수로 별도로 만든다
- 분해의 기준은 명확하지는 앖지만 너무 빽빽하지만 않으면 된다는 기준도 있다
## 코드 분해 방법
### 리퍢터링을 통한 코뜨 분해
- 프로그래밍을 하다보면 짧은 시간에 많은 양의 코드를 작성하거나 기존 코드에 여러 기능을 추가하기도 한다
- 이러다 보면 코드 베이스의 길이가 길어지면서 누더기 코드로 변하게 된다
- 리팩터링이란 이;런 코드들의 구조를 다시 조정하는 작업이다. 
- 주기적인 리팩터링을 통해 코드를 이해하고 유지보수하기 쉬운 코드로 다시 작성한다
- 테스팅 프레임위크를 사용해 리팩터링 중 발생하는 버그를 막는다
